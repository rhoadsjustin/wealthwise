### Description

`WealthWise is a private, local-first budgeting app for tracking spending, planning savings, and staying ahead of monthly bills.

Add transactions quickly, organize them with flexible categories and budgets, track savings goals, and monitor recurring bills and debts in one place. WealthWise also includes on-device insights to help you understand spending patterns without relying on a cloud account.

Features:
- Track income and expenses
- Create custom categories and monthly budgets
- Monitor bills, debts, and savings goals
- Use Face ID / Touch ID or a passcode for app lock
- Get private on-device insights and category suggestions

WealthWise is designed for people who want practical money tracking with clear controls and minimal setup.`

`WealthWise is a local-first budgeting app. No account creation or demo login is required for review.

Important review notes:

- Face ID / Touch ID is optional and only used if the user enables App Lock.
- The Insights tab may download on-device models the first time the feature is used.
